## 2. 字典归档原则

1. 字典先于产品/SKU归档，SKU 的 `phone_brand`、`model_code`、`color_code`、`bom_code`、BOM物料和工艺节点都依赖字典。
2. 字典编码按文本保存，保留前导 0，例如手机型号 `0716`、颜色 `01`。
3. 名称字段只做展示和人工核对，不作为自动匹配主键。
4. 多语言字段先保留，不强行合并到一个名称字段。
5. 状态统一从 seed 的 `enabled` 映射到系统可用状态。
6. 发现重复编码或缺少上级关系时，先进入待清洗清单，不自动修正。

## 8. 字典落地顺序建议

1. 颜色字典：无上级依赖，且已有专用导入模板。
2. 品牌字典：无上级依赖，支撑手机型号和SKU品牌。
3. 手机型号字典：依赖品牌，但允许品牌为空时先暂存。
4. 工序字典：支撑工艺路线、BOM工序映射、报工/产能/领料规则。
5. 物料字典：支撑 BOM 行项目和库存中心。

如果要优先服务 SKU 归档，顺序可以改为：品牌、手机型号、颜色、产品、SKU、物料、工序、BOM。  
如果要优先服务 BOM 归档，顺序可以改为：颜色、产品、物料、工序、路线、BOM。

## 9. 导入前校验清单

| 校验项 | 处理建议 |
| --- | --- |
| 字典主键为空 | 阻断导入，进入清洗表 |
| 字典主键重复 | 阻断相关记录，人工确认合并或拆分 |
| 手机型号缺品牌 | 允许暂存，但标记 `brand_missing` |
| 颜色/机型/品牌名称为空 | 允许暂存，但展示主键并提示补名称 |
| 工序编码被路线引用但工序字典不存在 | 阻断路线，不阻断产品 |
| BOM物料编码在物料字典不存在 | 阻断对应 BOM 行，不阻断 SKU 主档 |
| 单位包含多语言混写 | 导入前标准化为系统单位，同时保留原始单位 |
| 状态不是 `enabled` | 默认不参与自动匹配，除非人工指定 |

## 10. 本次结论

字典层可以先作为后续产品/SKU归档的“地基”单独维护：

- 颜色、品牌、工序、物料主键质量较好，可以直接进入字段设计和导入模板准备。
- 手机型号字典需要先处理 `model_code=0716` 重复问题，并标记 116 条缺品牌编码的数据。
- SKU 归档时，`product_code + model_code + color_code` 必须能反查产品、手机型号、颜色三类资料。
- BOM 归档时，`child_code_normalized` 必须能反查物料字典，`target_process_code` 必须能反查工序字典。
