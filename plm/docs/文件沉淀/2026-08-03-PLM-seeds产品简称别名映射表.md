## 7. 使用规则

| 场景 | 建议处理 |
| --- | --- |
| 工艺路线中出现简称 | 先查“工艺路线名称映射”，映射到标准产品编码 |
| BOM父项出现英文或少空格写法 | 先查“BOM父项名称映射”，不要按名称新建产品 |
| 物料类型出现 `BA/BD/FA/FANT/FANP/waves` | 先查本表映射到产品，再判断它是物料、半成品还是成品 |
| 基础码如 `NBA1010`、`NBD1021` | 识别为产品工序状态码，不是产品线 |
| 基础码为 `4030/4020` 结尾且标记成品 | 可作为成品/SKU编码生成规则的一部分 |
| 名称无法映射 | 进入待确认表，不自动创建产品或SKU |

## 9. 本次结论

后续添加现有产品和 SKU 时，标准产品编码优先级应高于名称：

1. 先按产品编码前缀识别：`NBA/NBD/NDN/NFA/NFB/NHA/NWV`。
2. 再按别名映射补充识别：`Rainbow/Blindaje/Alterna/Fantasy/Titanio/Super Capitan/Waveshell`。
3. 再按工艺路线或BOM父项名称辅助判断。
4. 最后才用产品名称人工核对。

尤其要注意：工艺路线和物料板块里的简称不一定是标准产品名，不能直接作为产品/SKU主键。
