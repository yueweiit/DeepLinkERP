# 2026-07-29 PLM 导入物料模板字段重定义沉淀

## 1. 背景

本次按用户提供的物料表截图，重新定义“数据导入/导入物料”的下载模板。旧模板采用后端字段名和通用库存字段：

```text
inventory_code, inventory_name, inventory_type, specification, unit, supplier_name, unit_cost, currency_code, status, remark
```

该模板对业务用户不友好，也把“物料类型、供应商、币种、状态”等系统字段暴露给首批历史物料导入。截图中的实际业务维护口径更接近 ECOUNT 物料编码明细表，因此新模板改为业务中文字段。

## 2. 新模板字段

Sheet 名称仍为 `inventory_template`，避免影响现有导入入口和自动选 Sheet 逻辑。

| 顺序 | 新模板字段 | 是否必填 | 来源理解 | 后端字段/规则 |
| ---: | --- | --- | --- | --- |
| 1 | `物料组` | 是 | 一级物料组名称，例如 `原料`、`辅料`、`工具`、`模具` | 作为 ECOUNT 物料组名称导入，参与派生 `inventory_type`；后续若存在物料组字典，优先关联物料组。 |
| 2 | `物料编码` | 是 | 现行物料编码，例如 `YL000002`、`GJ000260` | 映射 `inventory_code`，文件内和库内不能重复。 |
| 3 | `物料名称` | 是 | 物料名称或物料族名称，例如 `原料PC`、`羊毛球` | 映射 `inventory_name`。 |
| 4 | `规格型号` | 否 | 规格、型号、材质、包装描述，例如 `黑色/NEGRO/25Kg-袋` | 映射 `specification`。 |
| 5 | `规格` | 是 | 截图中实际为单位，例如 `kg`、`个`、`套`、`L` | 映射 `unit`，落库到 `plm_inventory.stock_uom`。 |
| 6 | `新增日期` | 否 | ECOUNT 维护日期，例如 `2020/2/13` | 映射 `source_created_date`，当前追加进 `remark` 做历史追溯。 |

## 3. 默认值与落库策略

新模板不再要求用户填写旧模板中的系统字段，导入层自动补齐：

| 系统字段 | 默认/派生规则 |
| --- | --- |
| `inventory_type` | 由 `物料组` 派生：原料/钢料/铜料归 `material`；辅料归 `packaging`；工具/模具/模架/模芯/设备归 `tooling`；加工/费用/日常工作归 `unsupported` 并在预览报错。 |
| `supplier_name` | 空值统一为 `默认供应商`。 |
| `unit_cost` | 新模板不提供，落库为空。 |
| `currency_code` | 默认 `CNY`。 |
| `status` | 默认 `available`。 |
| `remark` | 追加 `ECOUNT导入：一级=<物料组>，新增日期=<新增日期>`，提交时继续追加 `历史存档导入`。 |

## 4. 旧模板下线与兼容

旧 10 列英文模板从下载入口下线，不再作为“导入物料模板”暴露给用户。

为避免历史文件无法导入，解析层继续兼容旧模板字段名和旧中文别名：

- `inventory_code`、`新物料编码`、`库存编码` 仍可映射为 `inventory_code`。
- `inventory_name`、`库存名称` 仍可映射为 `inventory_name`。
- `物料类型`、`库存类型`、`inventory_type` 仍可直接写系统枚举。
- `单位`、`基本单位`、`库存单位` 仍可映射为单位。
- 当同一行表头同时出现 `规格型号` 与 `规格`，`规格型号` 作为规格描述，`规格` 按截图语义作为单位处理。

## 5. 验收口径

1. 下载 `inventory` 导入模板时，首行只出现 `物料组、物料编码、物料名称、规格型号、规格、新增日期`。
2. 用新模板上传预览时，能够正确得到 `inventory_code`、`inventory_name`、`specification`、`unit`、`source_created_date`。
3. 新模板中 `物料组=原料` 可派生为 `material`，`物料组=工具/模具` 可派生为 `tooling`，`物料组=辅料` 可派生为 `packaging`。
4. 新模板不要求填写供应商、币种、状态、单价。
5. 旧英文 10 列模板仍可作为历史兼容文件导入，但不再由模板下载入口生成。
