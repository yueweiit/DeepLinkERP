# PLM 冻结发布 BOM 与工艺路线修数放开方案

日期：2026-08-05
状态：已实施
范围：仅放开 BOM 与工艺路线的编辑/导入/重算限制；不改变归档数据只读规则；不改发布冻结状态本身。

## 1. 背景

当前导入数据发现有误，需要在不回滚状态机的情况下直接修正历史 BOM 和工艺路线。
原实现中，`released` / `frozen` 状态会阻断部分保存和导入操作，导致修数困难。

## 2. 本次调整

1. BOM 工作台允许对 `released` / `frozen` 版本继续维护明细、路线和成本；
2. BOM 导入允许写回 `released` / `frozen` 版本；
3. 工艺路线允许对 `locked` 版本继续编辑；
4. `archived` 仍然保持只读和禁止修改；
5. 删除版本仍保持保守限制，不随本次修数窗口放开。

## 3. 影响范围

- 后端：`ProductBomWorkflowService`、`ProductBomServiceImpl`、`BomImportServiceImpl`、`ProcessRouteServiceImpl`
- 前端：`ProjectBomPanel.vue`、`ProjectProcessRoutePanel.vue`
- 测试：冻结 BOM 编辑、锁定路线编辑相关用例

## 4. 维护建议

1. 修数完成后尽快恢复更严格的编辑边界；
2. 后续如需长期保留修数能力，建议增加明确的“修订/纠错”入口，而不是长期依赖放开冻结规则；
3. 对已发布数据的修正应保留操作日志和备注追溯。
