# PLM 模具编码导入、产品关联与钉钉匹配代码实现沉淀

日期：2026-08-04  
状态：已实现，待业务验收

## 1. 本次改动

1. 新增 `plm_product_mold_code` 关系表。
2. 新增产品-模具编码关联服务。
3. 导入能力新增 `product_mold_code` 类型。
4. 钉钉新型号来源产品改为先查模具编码关联。
5. 产品详情接口增加模具编码明细返回。
6. 前端 `getProductDetail` 已接入真实接口。

## 2. 关键规则

- 只导入系统已有的 Product。
- 导入时不创建 Product 主数据。
- 绑定失败直接报错，不随机匹配。
- 钉钉匹配优先使用完整模具编码关联，必要时再回退到基础前缀。

## 3. 代码位置

- 关系表迁移：`plm-server/src/main/resources/db/migration/V20260804_1100__product_mold_code_relation.sql`
- 关联服务：`plm-server/src/main/java/com/yuewei/plm/module/product/mold/service/ProductMoldCodeService.java`
- 钉钉匹配：`plm-server/src/main/java/com/yuewei/plm/module/integration/dingtalk/service/DingTalkModelVariantService.java`
- 导入扩展：`plm-server/src/main/java/com/yuewei/plm/module/importexport/service/impl/MasterDataImportExportServiceImpl.java`
- 产品详情 VO：`plm-server/src/main/java/com/yuewei/plm/service/vo/ProductVO.java`
- 前端详情 API：`plm-web/src/api/modules/product.ts`

## 4. 实现结果

- `mould.xlsx` 可作为模具编码关联数据源。
- 产品详情可返回 `moldCodes` 和 `moldCodeDetails`。
- 钉钉新型号可根据已导入模具编码解析来源产品。
- 同时传入固定 `parentProductId` 时，会校验是否与模具编码关联一致。
