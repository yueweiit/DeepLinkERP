# 中国财务入口选择公司

## 操作

1. 点击桌面“中国财务”，弹出“选择公司”，选择有权访问的非集团公司并确认。
2. 进入中国财务工作台，顶部显示“当前公司：公司全称”。点击该按钮或再次点击“中国财务工作台”可重新选择。
3. 打开“查凭证”、财务报表、科目映射控制台、银行对账或其他带公司字段的列表，会带入所选公司。
4. 从带公司筛选的列表点击“新建”，新单据自动带入该公司。已保存单据仍使用其原有公司。

“查凭证”菜单继续保留，只移除原先进入该报表时重复出现的选公司弹窗。进入中国财务仍显示工作台。

取消弹窗不会改变已选公司；从其他页面点击入口后取消，会留在原页面。直接访问工作台地址或刷新工作台时也会弹窗，并默认上一次选择。

## 公司作用范围

- 公司选择保存在当前用户、当前浏览器标签页中，不修改站点默认公司或用户默认公司。
- 从中国财务工作台或侧边栏打开页面，会以当前所选公司覆盖该页面上一次的公司筛选，其他筛选参数保留。页面内仍可按原功能手工修改公司筛选。
- 通过搜索、其他模块或已有单据链接进入页面，仍遵循对应入口的筛选和权限。直接打开报表时，已有明确公司筛选优先；没有公司筛选时使用中国财务已选公司或用户默认公司。
- 不带公司字段的公共配置（例如财务报表模板）不加公司筛选。选择公司不替代 ERPNext 原有权限校验。
- 银行对账使用 ERPNext 自带的公司选择存储。重新进入时会同步所选公司；切换公司时重新加载银行对账界面，随后选择该公司的银行账户。

## 服务器更新

按现有自定义镜像发布流程更新代码及静态资源到运行容器。新增的 `company_context.js` 必须能够通过 `/assets/china_finance/js/company_context.js` 访问。

在 backend 容器的 `~/frappe-bench` 目录，按现有部署流程执行：

```bash
bench --site deeplinkerp.com migrate
```

```bash
bench --site deeplinkerp.com clear-cache
```

随后按现有流程重启服务，浏览器 `Ctrl+Shift+R` 强制刷新。本次功能无需修改、取消或重新提交财务凭证。

## 验证

1. 点击“中国财务”，确认出现公司选择弹窗，确认后进入工作台。
2. 打开“查凭证”和“记账凭证”，确认公司与选择一致；“查凭证”不重复弹窗。
3. 回工作台切换另一家公司，再次打开刚才的页面，确认已缓存页面也更新公司。
4. 从记账凭证列表新建一张单据，只检查公司字段即可，不必保存。
5. 检查科目映射和银行对账带入公司；取消选公司弹窗后，原选择保持不变。

前端回归检查（在 `apps/china_finance` 目录）：

```bash
node --test china_finance/tests/test_company_context.js
```

本地验证通过 11 项前端回归检查。另在 `dev.localhost` 实际浏览器验证了桌面入口弹窗、工作台显示当前公司、缓存凭证报表切换、列表公司筛选、新建未保存凭证的默认公司，以及直接访问或刷新工作台后的弹窗。未保存或提交测试凭证，未操作服务器数据。
