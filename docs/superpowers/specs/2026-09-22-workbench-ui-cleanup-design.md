# 综合成本工作台界面清理设计

## 目标

在不改变成本核算、整改提交和资料分析业务规则的前提下，修正整改抽屉输入区过窄、详情页置顶头部留缝，并完整删除“查看资料来源”这一独立入口及其专用实现。

## 设计

1. 整改抽屉继续复用现有组件和 `520px` 宽度。问题来自 Frappe 全局 `label` 样式使表单标签按内容收缩，因此让整改卡片的直接表单标签占满卡片宽度，并让文本框使用完整盒模型；不新增第二套抽屉或表单。
2. 详情页头部继续粘附在实际滚动容器 `.main-section` 中，只把粘附偏移从 `12px` 改为 `0`，保留现有层级、阴影和响应式规则。
3. 删除“查看资料来源”按钮、事件绑定、弹窗渲染与打开函数、仅供该弹窗使用的样式、后端白名单接口和相应测试。保留装箱资料获取、AI 分析、钉钉审批、历史附件和底层资料来源服务，因为这些仍被其他业务流程调用。

## 验证

- 测试先证明现状不满足：输入区不是全宽、sticky 偏移仍为 `12px`、资料来源专用 UI/接口仍存在。
- 实现后运行相关前端测试、受影响测试、资源构建并重复到 `changed: []`。
- 浏览器验收桌面、窄屏和手机宽度；滚动 `.main-section` 验证头部贴顶且无横向溢出。

## 边界

- 不删除底层来源数据、来源选择、AI 分析或历史审计能力。
- 不新增兼容分支或隐藏式替代入口。
- 本次不改变整改写入、附件上传、权限、状态流转或 ERP 规则。
