# 装箱计划表默认入口、排序与 Sheet 推荐设计

日期：2026-09-07。状态：交互方向已由用户确认，等待书面设计复核后实施。

## 1. 已确认的体验

- “知识库年度表”在所有用户界面统一更名为“装箱计划表”；数据库内部兼容字段和已有来源类型不因改文案而迁移。
- 打开“获取装箱单与比较运费”弹窗时，默认进入“装箱计划表”，来源顺序固定为：
  1. 装箱计划表
  2. 钉钉审批附件/评论
  3. 本地上传
- 系统自动选中一张有充分依据的推荐 Sheet，但选择不等于确认。用户必须点击常驻底部的“预览这张装箱计划”，检查装箱行、共享包装组、毛重和体积后，才能进入确认写入。
- 未取得可靠推荐时不自动选中普通 Sheet，并显示“暂无可靠推荐，请手动选择”。
- 推荐项置顶；其余 Sheet 按业务日期由近到远排列，无法识别日期的项目排在最后。

## 2. 方案取舍

采用 A：缓存内容匹配 + 审批关系 + 日期的混合推荐。

- A（采用）：用已有快照核对批次物料，再结合主国际物流审批、关联采购审批及 Sheet 日期。准确、可解释，不需要打开弹窗就刷新全年 25 张 Sheet。
- B：只按 Sheet 名和日期推荐。实现简单、调用少，但“最近”不代表属于当前批次，误选风险高。
- C：每次打开都刷新全年所有 Sheet 后推荐。内容最及时，但延迟大、钉钉 API 调用多，且任一 Sheet 权限或网络异常都会拖慢用户。

若推荐 Sheet 尚无缓存，A 方案允许用名称和审批号给出低置信候选，但必须明确显示“内容待刷新”；不能把它标为高置信推荐。

## 3. 服务端推荐规则

推荐在服务端完成，浏览器只接收白名单摘要、分数等级和解释，不接收审批 `raw_payload` 或整张表的未筛选内容。

### 3.1 候选数据

- 当前批次：批次号、物流单号、业务类型、物料编码、物料名称、数量。
- 主国际物流审批：流程实例号、审批编号、表单中的采购单号/物流号/项目或产品关键词。
- 全部关联采购支出审批：实例号、采购审批号、订单号、物料编码和可用的产品关键词；一次批量读取，禁止逐个审批查询。
- 装箱计划表索引：Sheet ID、名称、文档年份、源更新时间、最新快照时间。
- 已有快照摘要：物料编码集合、采购审批号集合、主体行数、包装组数、异常数和内容哈希。

只使用成本系统有权读取的白名单流程和白名单工作簿。

### 3.2 日期排序

从 Sheet 名识别 `YYYY.M.D`、`YYYY-MM-DD`、`M.D`、`M月D日` 等日期；缺少年份时使用所属装箱计划表的年份。日期解析失败时不猜测。

排序优先级：

1. 推荐 Sheet 独立置顶。
2. 可识别业务日期降序。
3. 源更新时间降序。
4. 最新快照时间降序。
5. Sheet 名和 Sheet ID，保证相同数据每次顺序稳定。

Sheet 名日期和表内计划出货日期继续分别保存，排序不能把两者合并成同一个事实。

### 3.3 评分与置信度

每张候选 Sheet 生成 0—100 的基础分，并保留逐项证据：

- 当前批次物料编码覆盖率：最多 60 分。
- 主审批或关联采购审批号/订单号精确命中：最多 25 分。
- 批次号、物流号、项目或产品关键词命中：最多 10 分。
- 与当前业务日期接近：最多 5 分。
- 快照出现批次外物料时最多扣 10 分；只降低置信度，不直接删除候选，因为一张装箱计划可能包含相关辅料或混装物料。

置信度规则：

- 高：有缓存内容，且当前批次 SKU 覆盖率 100%，或 SKU 高覆盖并有审批号精确命中。
- 中：有缓存内容，但只部分匹配；或没有 SKU 证据但有审批号精确命中。
- 低：仅名称、关键词或日期相似。
- 不推荐：没有正向业务证据，或来源状态不可用。

相同最高分时，依次比较审批精确命中、SKU 覆盖率、业务日期和 Sheet ID。任何分数都不能绕过用户预览和来源版本复核。

### 3.4 当前真实批次的预期推荐

批次 `202609032107000062462` 当前包含 5 个物料编码：`FL000427`、`FL000428`、`FL000429`、`FL000430`、`FL003377`。

已刷新快照显示 `指环扣-packing list2026.9.05` 命中上述 5/5 个物料编码，因此应成为高置信推荐。快照另含 `CW000224`，界面必须同时提示“含 1 个批次外物料，预览时确认”，不能因为 5/5 命中就自动写入。

## 4. 前端设计

### 4.1 首屏

打开弹窗后：

- “装箱计划表”Tab 默认激活。
- 推荐卡片置顶并自动选中，展示“系统推荐”“高/中/低置信度”、Sheet 日期、刷新时间和 2—3 条关键证据，例如“匹配当前批次 5/5 个 SKU”“含 1 个额外物料”。
- 普通列表紧随其后，按最近到最远排列；每项显示 Sheet 名、识别日期、缓存/刷新状态。
- 仍保留搜索和“刷新资料”。刷新只作用于用户明确选择的 Sheet，不批量刷新全年表。

### 4.2 明确的下一步操作

当前“选择后按钮在长列表底部看不到”的问题通过弹窗内常驻底部操作栏解决。操作栏始终显示：

- 当前选择：Sheet 名。
- 主按钮：“预览这张装箱计划”。
- 次要操作：取消或关闭。

未选择时主按钮禁用。点击主按钮后进入数据预览，不直接写批次；来源版本、快照哈希或内容在确认前发生变化时，要求重新预览。

### 4.3 预览与合并单元格

预览继续显示物料匹配、批次外物料、共享包装组、毛重、体积和异常。上传 Excel 时使用文件内真实合并范围；钉钉表格 API 未提供合并范围时，空白只能形成待确认的候选包装组，不能盲目向下复制或重复计重。

存在批次外物料、共享组歧义、行合计冲突或来源变化时，“确认装箱数据”保持受控状态；用户明确处理后才可写入。运费比较仍是独立试算，不修改正式费用。

## 5. 接口变化

扩展现有装箱来源列表响应，不增加浏览器对钉钉的直接调用：

```text
display_source_name
business_date
source_updated_at
snapshot_updated_at
snapshot_status
recommendation_score
recommendation_confidence
recommendation_reasons[]
matched_item_codes[]
missing_item_codes[]
extra_item_codes[]
is_recommended
```

批次、主国际物流审批和关联采购审批必须批量读取。推荐计算可以复用缓存摘要；打开弹窗本身不得触发 25 张 Sheet 的内容刷新。

为兼容已经部署的来源类型，后端枚举和数据库表名可继续使用 `wiki` / `workbook`，仅用户可见名称统一改为“装箱计划表”。

## 6. 测试与验收

- 打开弹窗默认选中“装箱计划表”，三个来源顺序符合设计，旧文案不再出现在可见界面。
- 长列表滚动时操作栏仍可见；仅选中不会写入，必须点击预览并完成确认。
- Sheet 名中的完整日期、无年份日期、中文日期和未知日期排序正确、稳定。
- 推荐查询一次取得主审批与关联采购审批，不产生 N+1 查询，不直调钉钉。
- 缓存内容、审批号、关键词、日期、额外物料及并列分数均有覆盖测试。
- 当前真实批次推荐 `指环扣-packing list2026.9.05`，显示“匹配 5/5 个 SKU”和额外 `CW000224` 风险提示。
- 无可靠证据时不强行推荐；快照待刷新、失效或无权限时给出准确状态。
- 合并单元格候选、共享箱级重量/体积和批次外物料未经确认不写入，也不重复计重。
