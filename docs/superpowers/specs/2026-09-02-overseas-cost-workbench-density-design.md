# 海外采购综合成本工作台信息密度与明细交互设计

日期：2026-09-02

分支：`overseas_costing`

基线提交：`067ed6f7205f78bda5308208f01cd7f12bfcec4c`

## 背景

当前工作台把运输方式统计、七个查询字段、批次列表、行级操作和 SKU 全字段明细同时放在首屏。批次行单击会展开 SKU，双击才打开详情抽屉，但页面没有足够明显的双击提示。SKU 明细最小宽度约 5320px；虽然已有横向滚动条和前两列冻结样式，但滚动入口受系统原生滚动条显示设置影响，鼠标用户难以发现。

本次只调整工作台前端的信息架构、交互入口和布局，不改变综合成本计算、数据拉取、凭证、ERP 回写及后端权限规则。

## 目标

1. 首屏先帮助用户定位批次和判断状态，减少同时出现的控件与说明文字。
2. 报关/来源单号单击即可打开详情抽屉，不再依赖隐藏的双击操作。
3. SKU 明细仍可在批次下方展开，但只能通过左侧展开按钮触发。
4. 让普通鼠标用户明确知道 SKU 表格可以横向浏览，并能点击、拖动或按字段组跳转。
5. 采购与财务用户看到更贴近各自任务的默认列，同时不改变数据权限。

## 非目标

- 不重做成本计算逻辑、费用池、分摊公式或后端接口。
- 不改变已有单据、字段和 ERP 队列的数据结构。
- 不增加移动端专用交互。
- 不在本次工作中重构与页面改造无关的历史代码。

## 总体方案

采用“渐进式列表 + 详情抽屉”：列表只承担定位、状态判断和快速操作；完整上下文进入抽屉；SKU 全字段明细由独立展开入口按需显示。

页面从上到下分为四层：

1. 标题与主要动作。
2. 运输方式横向筛选标签及收起式高级查询。
3. 采购/财务角色视图下的批次列表。
4. 按需展开的 SKU 明细表和固定横向导航器。

## 页面结构

### 顶部区域

- 保留页面标题和一个主按钮“添加报关运单”。
- “凭证对比”“商品归类”“钉钉拉取”“Excel 导入”“导出”等动作归入次级操作区或“更多”，减少同一行的按钮数量。
- 当前默认数据范围以紧凑提示呈现，不占用整行大色块。

### 运输方式

- 删除常驻左侧运输方式侧栏。
- 改为列表上方的横向标签：全部、海运、空运、快递，并显示批次数量。
- 标签单击立即筛选；当前选择有明确高亮。
- 行数和物料数不在每个标签中重复展示，需要时放入提示或汇总区。

### 查询区

- 默认显示最常用的报关/来源单号、运单号和物料关键字。
- 其他字段放入“高级筛选”展开区。
- 查询、重置与结果数量保持在同一视觉组，不再铺满七列输入框。
- 保留字段可单独或组合查询的能力，筛选逻辑不变。

## 批次列表交互

### 单击与展开

- 单击“报关/来源单号”链接打开该批次详情抽屉。
- 不再监听批次行双击，不再使用“ 双击查看批次详情 ”作为提示。
- 单击行的其他非交互空白区域只做行选中/高亮，不打开、不展开。
- SKU 只由最左侧的展开/收起按钮控制。按钮使用箭头或加减号、具备 `aria-expanded`，并显示“展开 SKU 明细”提示。
- 行内按钮、链接和表单控件继续阻止事件冒泡，避免误开抽屉或误展开。

### 行内容

列表默认只保留用户做判断所需的信息：单号、运输方式、SKU 数、资料状态、采购货值、费用状态、综合成本、凭证/ERP 状态与操作。

连续说明文字合并为状态副文案；同一行最多保留一个主操作和一个“更多”入口。低频操作进入“更多”菜单。

### 角色视图

- 采购视图优先展示资料完整性、采购货值、费用来源和重新计算等信息。
- 财务视图优先展示已识别费用、综合成本、凭证差异、确认结果和 ERP 回写状态。
- 角色视图只影响默认列和操作排序，不扩大数据访问权限。
- 只有一种业务角色时直接使用对应视图；同时具备两种角色时显示“采购视图 / 财务视图”切换并记住用户最近选择。
- 现有“成本列表 / ERP 队列”仍是业务页面切换，不与角色视图混为一个开关。

## 详情抽屉

- 抽屉由单号链接、ERP 队列的打开动作或带批次参数的直达链接打开。
- 抽屉顶部固定显示单号、运输方式、核心状态和关闭按钮。
- 信息按“概览、资料与来源、费用与分摊、凭证与 ERP”分组，采购与财务视图可调整默认标签，但内容和权限一致。
- 抽屉概览不再重复渲染大块 SKU 全字段表，只显示 SKU 数和关键汇总；需要逐项查看时回到列表展开 SKU，或进入抽屉内明确命名的 SKU 标签。
- 关闭抽屉后保持原筛选、滚动位置和展开状态。

## SKU 明细与横向浏览

### 冻结列

- A“物料编码”固定宽度 160px。
- B“产品名称”固定宽度 260px，左偏移恒定为 160px。
- 表头和单元格均允许换行，最多两行；超出内容省略，鼠标悬停或键盘聚焦时显示完整值。
- 行高统一约 56px。即使冻结列换成两行，右侧费用字段也保持同一行对齐。
- 两个冻结列必须使用不透明背景和正确的 `z-index`，避免横向滚动内容从其下方透出。

### 横向导航器

- SKU 区域底部显示常驻自定义横向导航器，不依赖操作系统是否自动隐藏原生滚动条。
- 导航器包含左移一屏、可拖动滑块、右移一屏和“当前 A–H / 全部 A–BE”范围提示。
- 上方提供字段组跳转：基础信息、采购数据、物流费用、税费、综合成本。单击后滚动到该组第一列，并同步范围提示。
- 右边缘保留渐隐提示，表示后面仍有字段。
- 鼠标悬停在 SKU 表格时支持 `Shift + 滚轮`横移，作为补充操作；普通滚轮继续纵向滚动页面。
- 自定义导航器和实际表格双向同步：拖动导航器更新表格，直接滚动表格也更新滑块位置。
- 列不足一屏时隐藏导航器和渐隐提示。

## 状态、异常与可访问性

- 加载批次或 SKU 时在对应区域显示骨架或加载状态，避免整页阻塞。
- 抽屉加载失败时保留抽屉框架并提供重试；不清空列表筛选状态。
- 横向导航的左右按钮在起点和终点禁用；键盘可聚焦，支持方向键、PageUp/PageDown 或等价键盘操作。
- 所有仅图标按钮提供可见提示、`aria-label` 和足够的点击面积。
- 状态不能只依赖颜色，同时保留文字或图标。
- 视口较窄时优先保持冻结列和导航器可用，不把完整 5320px 表格缩放到不可读。

## 代码边界

主要改动集中在：

- `overseas_costing/overseas_costing/page/overseas_cost_workbench/overseas_cost_workbench.js`
- `overseas_costing/overseas_costing/page/overseas_cost_workbench/overseas_cost_workbench.css`

实现时把横向导航同步、角色视图选择和批次行交互拆成小函数，避免继续扩大现有事件绑定和渲染函数。仓库中另有一份相似页面源码；实施前先确认构建入口，并只同步确实参与发布的副本，避免两份代码继续漂移。

## 验收标准

1. 新用户不看说明也能通过单击单号打开抽屉，并能通过左侧按钮展开 SKU。
2. 双击批次行不会产生额外行为；单击单号不会先展开 SKU。
3. 普通鼠标用户在 SKU 区域内始终能看到并操作横向导航器。
4. A、B 两列在横向移动到任意字段组时保持冻结，宽度分别为 160px 和 260px。
5. 长编码和长产品名最多显示两行，完整内容仍可访问，所有 SKU 行保持对齐。
6. 字段组跳转、左右翻屏、拖动滑块和表格自身滚动保持同步。
7. 采购与财务默认列符合各自任务，同时现有权限、筛选、计算、凭证和 ERP 操作结果不变。
8. 关闭抽屉后恢复原列表上下文；加载失败可在局部重试。

## 测试建议

- 为单击单号、展开按钮、行空白、行内操作按钮分别验证事件互斥。
- 用短值、超长中英文值、连续无空格编码验证两行截断、提示和冻结偏移。
- 用不同 SKU 数、字段列不足一屏和完整 A–BE 字段验证导航器显示条件与同步。
- 覆盖鼠标点击、拖动、滚轮补充操作及键盘操作。
- 覆盖采购角色、财务角色、双角色和无匹配业务角色的默认视图。
- 回归筛选、重新计算、资料查看、凭证、ERP 队列和直达链接。
