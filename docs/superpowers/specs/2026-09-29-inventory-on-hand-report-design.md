# 库存库位明细独立页面设计

日期：2026-09-29

## 目标

保留 ERPNext 标准“可用数量”，在库存侧边栏紧接其后新增独立的“库存库位明细”页面。页面只服务本次盘点来源追溯：既能查看物料在每个原始库位的数量，也能看到该物料在当前仓库的完整总库存。

固定列顺序为：正式物料编码、物料名称（双语）、仓库、原始库位、库位数量、总库存、库存单位、物料组、DPCI、外部编码、原始标识/别名。

## 复用优先结论

- 物料、仓库、物料组、DPCI、外部编码及别名继续复用标准 `Item` 和既有自定义字段。
- 标准 `Stock Projected Qty` 及其“可用数量”入口保持不变。
- 原始库位不是 ERP 仓库层级，也不创建货架子仓库；它来自盘点文件的不可丢失审计快照。
- 原始库位数据使用可导入的 `Inventory Original Location Snapshot` DocType 保存，导入走 Frappe 标准 Data Import，不保留一次性或平行写入接口。
- 页面使用 Frappe 标准 Page、权限和调用机制；筛选、物料跳转和 Excel 导出均在同一实现中完成。
- 删除已被本设计替代的 `Inventory On Hand` Script Report，不保留两套相近报表。

## 数据模型

一条快照记录代表一个“正式物料编码 + 仓库 + 原始库位”的数量。关键字段包括：

- 快照标识、日期、记账时间、时区和公司；
- 对应库存调账、正式物料编码、仓库、原始库位、库位数量和库存单位；
- 来源文件、来源工作表、来源行、来源原始编码和来源文件 SHA-256；
- 唯一幂等键，防止同一快照行重复导入。

2026-09-29 初始快照来自 `BASE DE INVENTARIO YUEWEI..xlsm` 的 `CONCENTRADO 汇总表 `。399 条库位记录对应库存调账 `MAT-RECO-2026-45827`；两个色母粒因库存单位纠正而改用最终 kg 编码，对应 `MAT-RECO-2026-45828`。415 个非零来源单元格汇总为 401 条唯一库位记录和 377 个物料仓库组，总量为 `746,610.49`。

## 页面行为

- 独立页面名称为“库存库位明细”，位于库存侧边栏“可用数量”下方。
- 支持公司、盘点快照、仓库、原始库位、物料编码/名称和物料组筛选，以及清除筛选。
- 正式物料编码只显示编码；点击后进入标准 Item 详情。
- 同一物料仓库组中，编码、名称、仓库、总库存、单位、物料组及追溯字段使用真实 HTML `rowspan` 合并；原始库位和库位数量逐行展示。
- 原始库位筛选只缩小可见库位行，总库存仍显示该物料仓库组的完整小计。
- 导出 Excel 使用真实合并单元格，结构与页面一致。
- 页面不增加编辑、图表、批量操作、排序或折叠功能。

## 数量格式

- `个、件、套、卷、包、张、片、支、条、台` 等计数单位，整数不显示小数；确有小数时显示两位。
- `kg` 等连续计量单位固定显示两位小数。
- 底层数量保持数值类型，显示精度不会改写库存数量。
- 色母粒最终编码 `FL007979` 和 `YL001974` 的库存单位为 `kg`；旧编码 `FL000164`、`YL000115` 只作为外部编码/别名保留追溯。

## 验收

- 标准“可用数量”仍指向 `Stock Projected Qty`，其下新增独立页面。
- 初始快照为 401 条库位记录、377 个物料仓库组；综合/IML/OEM 仓库分别为 143/126/132 条。
- 22 个多库位组在页面和 Excel 中使用真实合并单元格，总量保持 `746,610.49`。
- 物料编码显示不拼接名称，点击可进入对应 Item。
- 库位筛选不改变完整仓库小计；计数单位和 kg 的显示精度符合约定。
- 重复导入相同幂等键不会生成第二份快照记录。
