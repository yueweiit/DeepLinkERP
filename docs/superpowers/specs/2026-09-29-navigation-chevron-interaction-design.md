# DeepLinkERP 导航箭头独立交互设计

日期：2026-09-29

## 目标

统一调整 MES 风格侧栏中所有带子菜单的模块，而不是只处理“采购”：

- 点击模块图标或文字区域，进入该模块工作区。
- 点击最右侧箭头，只展开或收起该模块的子菜单，不改变路由，也不关闭整条侧栏。
- 没有子菜单的模块继续整行跳转。
- 桌面端和移动端遵循相同的点击区域划分。

## 复用与根因

继续复用现有导航树、路由链接、`bindNavigationBranchToggle`、`bindNativeSidebarClose`、原生侧栏关闭契约和 DOM-only 折叠状态，不新增菜单数据源或路由状态。

当前问题的根因是：带子菜单的模块使用一个覆盖整行的 `<a>`，箭头只是链接内部的 `<span>`。箭头没有独立交互边界，因此点击箭头会冒泡到模块链接并触发路由。

## 交互结构

带子菜单的模块行拆成两个并列控件：

1. 主导航链接：包含模块图标和文字，保留现有路由、权限、桌面展开恢复和移动端实际跳转后关闭侧栏的行为。
2. 箭头按钮：使用独立 `<button type="button">`，只调用现有分支展开/收起逻辑，不绑定路由关闭逻辑。

箭头按钮点击区为 36×36px，箭头图标约 18px。按钮保持透明背景，悬停和键盘焦点提供清晰反馈；展开状态通过 `aria-expanded` 表达，并提供包含模块名称的中文 `aria-label`。

没有子菜单的模块不增加箭头按钮，继续使用单一导航链接。

## 状态与样式

- 分支开关仍只更新现有 group class、branch `hidden`、DOM-only `data-user-collapsed` 和箭头方向。
- 点击箭头时不调用 `preventDefault` 之外的路由补丁，不改变 URL，也不调用移动端整栏关闭。
- 当前模块及子菜单高亮规则不变；视觉上主链接与箭头仍组成一行，整行高度保持约 40px。
- 未选中箭头继续使用已提亮的颜色，展开状态使用白色。

## 兼容与边界

- 规则按“是否存在子菜单”判断，覆盖 DLP Framework、AI 助手、中国财务、组织、会计、资产、采购、生产、项目、质量、销售、库存、设置、海外成本及未来新增的同类模块。
- 不按模块名称写特殊分支。
- 保留权限过滤、用户排序/隐藏、文件夹、深链接、浏览器前进后退、移动端遮罩和桌面收起按钮。
- 不修改 Frappe、ERPNext 或 `custom_filters`。

## 测试与验收

自动化测试新增独立业务场景：

- 任意带子菜单的模块，其主链接点击仍执行路由行为。
- 任意带子菜单的模块，其箭头点击只切换分支，不调用路由关闭逻辑。
- 箭头可重复收起/展开，并正确更新 `aria-expanded`、方向和 DOM-only 折叠标记。
- 手机宽度下，箭头点击不关闭整栏；主链接跨模块跳转后仍关闭整栏。
- 无子菜单模块保持原有单链接行为。
- DOM 结构不出现按钮嵌套链接等无效 HTML，重复渲染仍只有一个导航根节点。

本地浏览器验收覆盖 1280×800 和 375px：分别测试采购、生产以及至少一个其他带子菜单的模块，确认点击箭头 URL 不变，点击文字后才跳转。

## 变更与清理

- 修改现有行渲染和事件绑定，不新增平行导航实现。
- 将原先绑定在整行链接上的分支切换事件迁移到箭头按钮；确认无调用后删除旧的整行分支绑定路径及对应重复测试。
- 最终报告列明新增、修改、删除、测试场景、代码行数变化、重复逻辑和未处理技术债。
