# 删除工作台统计卡片行设计

## 目标

删除工作台任务页签下方的整排统计卡片。该行与“待处理／成本核对／ERP 队列”任务入口及下方列表信息重复，移除后让用户直接进入搜索筛选区。

## 界面范围

- “待处理”“成本核对”“ERP 队列”三个页签均不再渲染统计卡片行。
- 不提供折叠、占位或替代统计入口，删除后收紧上下间距。
- 保留三个任务页签、搜索、日期、业务类型、业务主体、核对状态、ERP 状态、列表及分页。
- 已通过 URL 保存的筛选状态继续生效；历史统计卡片产生的 `issue` 或 `review_warning` URL 参数仍能被服务端识别，避免旧链接失效，但界面不再提供相应快捷按钮。

## 实现边界

- 删除前端统计卡片渲染和卡片点击事件绑定。
- 为保持现有列表调用兼容，保留 `get_summary` 及其服务端统计结果；本次不扩大为后端接口清理。
- 不改变待处理、待核对、已核对及 ERP 队列的分类规则，不修改任何业务数据。

## 验收

- 三个任务页签下均不出现该统计卡片行，也不保留空白区域。
- 搜索筛选区紧接任务页签，布局和响应式显示正常。
- 切换任务、查询、重置、分页及浏览器前进后退行为不变。
- 自动测试、前端资源构建及语法检查通过后，通过现有 GitHub Actions 发布。
