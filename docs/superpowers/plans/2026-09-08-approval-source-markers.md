# 钉钉采购审批来源标注

## 已批准目标

装箱原表、导入结果、物料表及 SKU 基础信息显示黄色来源提示。区分未关联采购审批、采购审批待核实、未匹配本批采购明细、匹配不唯一和来源核验失败。提示不改变费用计算、采购事实或导入规则。

## 接口与实现

- `approval_link` 为只读元数据，字段为 `status`、`label`、`reason`、`approval_no`、`instance_id`；正常 `linked` 不显示警告。
- 复用批次物流审批验证及可信关联采购审批列表，一次本地归档查询核对本页物料。审批进行中也可关联，凭证缺失单独处理。
- 物料与 SKU 接口统一装饰状态。SKU 的基础信息及全部字段增加不可编辑的采购审批来源列。
- 装箱原表在行号后增加来源状态列，保留 Excel 单元格坐标。导入结果在采购审批号旁标注；可展开中文原因及已有标识。
- 初次预览及合并确认响应在 hash 和签名确定后增加提示。手动选择采购明细后，按 `source_rows` 更新原表动态提示，原始单元格和候选记录保持不变。

## 验证与发布

- 覆盖无标识、缺失归档、可信来源冲突、RUNNING 审批、查询失败、真实 XLSX 未匹配行、匹配后多行合并、签名稳定及继续确认写入。
- 前端覆盖提示只读、来源文字转义、坐标准确及正常行不误标；使用真实组件渲染进行浏览器布局检查。
- 沿用生产流水线发布，发布前备份数据库及镜像；不执行数据修复或重算，不自动推送 ERP。
