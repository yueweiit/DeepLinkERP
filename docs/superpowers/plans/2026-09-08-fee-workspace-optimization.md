# 费用工作区优化

用户确认的五项要求覆盖旧设计中的费用优先顺序和手动分摊选择。基于当前发布分支 4a92d3ec93 实施，独立工作树保留其他任务的在途修改。

设计：依次展示物料与装箱数据、费用与凭证、SKU 综合单价试算。费用只录金额、币种、状态、凭证及必要的范围；试算汇总移到第三区并提供开始试算按钮。人民币为默认币种，只允许 RMB、MXN、USD，兼容 CNY 归一化为 RMB。

系统规则：海运/港杂优先体积，空运/快递优先计费重，目的地配送优先毛重，清关/税费按货值。每笔费用的适用物料必须全部具备正值的首选依据，否则统一回退到全部完整的采购货值。不能仅分摊给有物理数据的行；货值也不完整时保留中文缺项提示。明确的零金额无需物理量或汇率，空金额仍为待补；指定范围、单行直接费用、Decimal 尾差守恒保持有效。自动选择只影响本次计算，不覆写历史录入依据。试算和费用状态共用算法，物料红格使用本次有效依据。

不采用仅隐藏错误或把全部费用固定按货值的方案：前者会漏费用，后者丢失已有物理量的分摊价值。
