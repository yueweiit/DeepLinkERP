# 月结缺少比较期报表模板

## 适用错误

期末智能结转的月结检查通过后，提交时报“未找到适用于小企业会计准则的 Balance Sheet 报表模板”，错误日志停在 `snapshot_statement` 生成 `comparison` 的调用。

内置 3.0 模板从 2026-01-01 生效。2026 年月结保存报表时，资产负债表会查询上一会计年度末（通常为 2025-12-31）的比较数据，其他报表查询上年同期。如果站点没有这些日期适用的模板，旧程序会在提交阶段失败，即使本期报表和日常结账检查都正常。

## 更新后的行为

- 月结检查新增“本期报表模板可用”和“比较期报表模板可用”，详情列出报表及所需日期。
- 缺少本期模板仍然阻止月结；缺少比较期模板作为警告提示。
- 缺少比较期模板的月结报表保存为不可修改的“草表”快照，保留本期金额和映射校验值。比较金额为未生成（JSON 中为 `null`），不会填成零。
- 比较期模板可用时，继续按原有逻辑计算比较数据并保存快照。计算错误仍会报错，不会自动转成草表。
- 年结及正式法定报表输出仍要求完整的比较数据和正式四表快照。草表快照不能作为正式报表导出。

## 服务器操作

1. 通过现有自定义镜像发布流程更新 `china_finance`，确保 backend、worker 等运行服务使用修复版本。只在宿主机拉代码不一定会更新运行中的应用。
2. 刷新原来的期末智能结转草稿，重新执行“对账 → 运行结账检查”。只有比较期模板警告而没有阻断项时，可以再次提交。
3. 提交后核对状态为已结账；若开启结账后冻结期间，核对公司冻结日期。缺少比较数据的报告在“中国报表快照”中显示为草表，结账档案保留这些草表及缺失原因。

本修复不需要调整共享报表模板的生效日期、变更公司会计准则或重新提交已经成功提交的 ERPNext 损益结转凭证。它不补录上年余额，也不改变总账。

## 后续正式报表

需要正式报表时，按真实账务补齐比较期模板、科目映射和比较数据，再完成正式报表就绪度检查。仅安装本期模板或修改模板日期不能替代历史数据准备。

已经随月结保存的草表是当时状态的审计记录，后续配置变更不会自动将其改为正式。需要按受控的重新开账、修订结账流程生成新的完整快照，原草表和原档案继续保留；不能直接修改旧快照内容或“编制状态”。
