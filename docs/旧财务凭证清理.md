# 旧财务凭证核查与清理

提供两个管理员维护命令：`preview_finance_cleanup` 只读核查指定公司的旧凭证；`cleanup_cancelled_finance` 根据已保存的核查文件，清理已取消的测试来源凭证及关联记录，也可显式纳入无来源中国会计凭证。清理命令默认只预览，只有 `apply:1` 才会删除。

两者均要求 System Manager，仅通过 bench 调用，没有网页接口，不在迁移或定时任务中自动执行。代码没有新增数据库字段、迁移补丁、前端资源或第三方依赖，更新到服务器实际运行的 `china_finance` 应用目录后即可使用，无需为这两个命令额外执行 migrate 或前端构建。

## 清理命令的范围和影响

- 只从原预览文件中选择已取消的 Journal Entry / Payment Entry，不自动取消已提交单据，也不删除草稿或损益结转来源凭证。预览后新增的来源凭证不会自动加入。
- 执行前重新核对站点、公司、来源状态和修改时间，并锁定待删记录。原来源已消失但还有关联记录时要求重新预览，避免静默遗漏。
- `include_orphan_snapshots:1` 只纳入原预览中明确标为来源不存在，且来源类型为 Journal Entry、Payment Entry 或 Period Closing Voucher 的中国会计凭证。来源现已恢复、残留总账/支付/预付款/库存分类账，或仍有业务引用时，整批阻止。
- 检查静态、动态和自定义关联字段，包括已取消的引用；关联记录跨公司、银行核销、范围外业务单据、有效总账、冻结期间及已提交后续损益结转均阻止清理。
- 已解除关联的支付分类账可清理。未解除关联的取消对冲记录，必须按日期、来源、科目、往来、关联凭证、币种、成本中心、项目和财务账簿分组后，本位币及账户币金额均为零；跨日期对冲也不会放行。
- 删除所选来源及其子表、允许清理的分类账、会计快照、现金流指定和同步异常。针对已经取消或来源已不存在的测试记录，不再运行取消及删除业务钩子，避免额外变更其他业务或编号。
- 保留科目、客户、供应商、银行账户、财务设置、报表模板和科目映射。银行交易及核销不自动修改；若有关联，先返回阻塞项。
- 删除前将完整父子记录及可识别审计记录导出到站点 `private/backups/cancelled-finance-*.json`，文件权限为 `0600`；同时保存到 `Deleted Document`。附件文件内容保留，File、Comment、Communication、ToDo、Version 的已识别关联转到对应删除归档；旧共享权限不转移到删除归档。
- 不重置站点命名序列或公司期间凭证字号，新凭证继续使用后续编号。会计列表和依赖快照的报表将不再包含被清理的测试记录。
- 所有数据库变更在同一事务内执行，任何失败整批回滚。失败前生成的私有导出文件会保留，方便诊断；该文件不是执行成功标志。

完整站点备份是恢复依据。`Deleted Document` 和记录导出供审计、核查使用，不应逐张恢复其中的总账、快照或来源记录，以免形成部分恢复。JSON/文本内的历史报表快照及业务模块内部状态无法仅靠关联字段完整识别，本工具仅适用于已核实的历史测试数据，不能作为日常正式账务的删除入口。

## 只读核查命令参考

其他环境使用时，将 `SITE` 换成真实站点名，将公司全称换成 Company 单据的准确名称。省略日期会核查该公司全部日期、全部状态的来源凭证；不会实施删除。

```bash
bench --site SITE execute china_finance.services.finance_cleanup.preview_finance_cleanup --kwargs '{"company":"公司全称"}' > finance-cleanup-preview.json
```

限制日期、仅查看已取消来源凭证：

```bash
bench --site SITE execute china_finance.services.finance_cleanup.preview_finance_cleanup --kwargs '{"company":"公司全称","from_date":"2026-07-01","to_date":"2026-07-31","cancelled_only":1}' > finance-cleanup-preview.json
```

日期筛选针对来源凭证，损益结转使用期间截止日期。对应冲销快照即使日期在范围外或仍为已提交，也会列入关联信息；后续修订单不会自动扩入范围。清理命令默认读取 bench 根目录下的原始核查文件；`preview_file` 参数也可指定绝对路径，相对路径统一按 bench 根目录解析，不受 bench 内部切换到 `sites` 目录影响。

| 原预览字段 | 含义 |
|---|---|
| `site`、`company`、`scope` | 查询站点、精确公司和筛选范围 |
| `source_counts`、`sources` | 来源凭证数量、状态和编号，docstatus 0/1/2 分别为草稿/已提交/已取消 |
| `related_counts`、`related_records` | 总账、支付分类账、会计快照、现金流指定、同步异常、结转处理及报表快照等关联清单 |
| `bank_transactions_to_preserve`、`bank_allocations_to_review` | 涉及的银行交易及其全部核销行，包括同一交易中的其他凭证 |
| `blockers` | 范围外引用、跨公司关联、业务引用、冻结期间及后续结转 |
| `other_accounting_vouchers_to_preserve` | 其他来源或找不到来源的中国会计凭证；清理命令默认保留，显式开关只放行上述受限的无来源情况 |
| `audit_and_attachment_links`、`attachments_to_preserve` | 可识别的附件和审计引用 |

单次查询超过 10,000 条会明确报错，不会截断清单后继续删除。超出当前规模时须针对实际数据另行核查分批方案。
